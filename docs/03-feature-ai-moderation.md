# 03. 기능 구현 지침: AI 악플 판별기

사용자가 입력한 댓글을 OpenAI API로 분석하고, 결과에 따라 경고등/초록불 및 강아지 표정을 제어하는 지침입니다.

---

## 1. 기능 요구사항 상세
1. **입력 검증**:
   - 입력창이 비어있거나 공백만 있는 경우 API를 호출하지 않고 `"댓글을 먼저 입력해주세요."` 안내 메시지를 띄웁니다.
2. **로딩 상태**:
   - `[판별하기]` 버튼 클릭 시 버튼을 비활성화하고 `"AI가 댓글을 분석 중입니다..."` 로딩 표시를 보여줍니다.
3. **판별 결과 분기**:
   - **악플인 경우 (`isMalicious === true`)**:
     - 신호등: **빨간색 경고등** 점등 (깜빡임/글로우 효과 권장)
     - 강아지: **화난 표정**으로 변경
     - 문구: `"악플입니다."` (필요시 간단한 사유 1줄 추가 가능)
   - **악플이 아닌 경우 (`isMalicious === false`)**:
     - 신호등: **초록불** 점등
     - 강아지: **웃는 표정**으로 변경
     - 문구: `"악플이 아닙니다."` + **"다시 입력해주세요"** 안내 문구 표시 (입력창을 비우거나 포커스를 주어 바로 새 댓글을 입력할 수 있게 유도)

---

## 2. OpenAI 프롬프트 설계 가이드 (백엔드)
- 모델: `gpt-4o-mini`
- 응답 형식: 반드시 JSON (`{ "isMalicious": boolean, "reason": string }`)으로 반환하도록 `response_format: { type: "json_object" }` 옵션을 사용합니다.
- 시스템 프롬프트 예시:
  > "너는 한국어 댓글의 악성 여부(욕설, 비하, 혐오, 인신공격, 성희롱 등)를 판별하는 AI다. 입력된 댓글을 분석하여 반드시 JSON 형식으로만 응답하라. 악플이면 isMalicious를 true, 아니면 false로 설정하고 reason에 짧은 한국어 이유를 적어라."

---

## 3. 완료 및 검증 기준
- [ ] 욕설/비하 문장 입력 시 빨간 경고등 + 화난 강아지 + `"악플입니다."`가 표시되는가?
- [ ] 정상적인 칭찬/일상 문장 입력 시 초록불 + 웃는 강아지 + `"악플이 아닙니다."` + `"다시 입력해주세요"`가 표시되는가?
- [ ] 빈 값 입력 시 에러 없이 안내 문구가 출력되는가?
