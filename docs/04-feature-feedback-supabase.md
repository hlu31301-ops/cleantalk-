# 04. 기능 구현 지침: 피드백 작성 및 Supabase 연동

로그인 없이 사용자가 서비스 피드백을 남기고, 화면 아래에 최신순으로 모든 피드백을 보여주는 기능 구현 지침입니다.

---

## 1. Supabase 데이터베이스 테이블 설계
Supabase 대시보드 > SQL Editor에서 아래 쿼리를 실행하여 `feedbacks` 테이블을 생성합니다.

```sql
CREATE TABLE feedbacks (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  nickname TEXT DEFAULT '익명',
  content TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

- **Row Level Security (RLS)**:
  - 로그인 없이 누구나 읽고 쓸 수 있어야 하므로, `feedbacks` 테이블에 대해 `SELECT`와 `INSERT` 권한을 허용(Enable Read/Insert for anon)하거나 백엔드에서 처리합니다.

---

## 2. 프론트엔드 동작 흐름 (`public/app.js`)
1. **페이지 로드 시 (`DOMContentLoaded`)**:
   - `GET /api/feedback`을 호출하여 저장된 피드백 목록을 가져옵니다.
   - 화면 하단 목록 영역에 **최신순(created_at 내림차순)**으로 렌더링합니다.
2. **피드백 전송 시**:
   - 닉네임(비워두면 `'익명'`)과 피드백 내용(`content`, 필수)을 입력받아 `POST /api/feedback`으로 전송합니다.
   - 전송 성공 시 입력창을 초기화하고, 피드백 목록을 즉시 새로고침하여 방금 작성한 글이 맨 위에 보이도록 합니다.

---

## 3. 보안 및 검증 규칙
- **XSS 방지**: 피드백 내용을 화면에 출력할 때 `innerHTML` 대신 `textContent`를 사용하여 스크립트 삽입 공격을 방지합니다.
- **빈 내용 방지**: 피드백 내용이 비어있으면 전송 버튼을 눌러도 서버로 보내지 않고 안내 메시지를 띄웁니다.
