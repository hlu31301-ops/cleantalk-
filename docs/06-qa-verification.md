# 06. 완료 및 검증 기준 (QA Checklist)

Antigravity AI 에이전트가 구현을 마친 후, 스스로 또는 사용자와 함께 확인해야 하는 최종 검증 기준입니다.

---

## 1. 기능 검증 (Functional QA)
| 번호 | 검증 항목 | 기대 결과 | 통과 여부 |
| :--- | :--- | :--- | :---: |
| 1 | 악플 입력 테스트 (예: 욕설/비하) | `"악플입니다."` + **빨간 경고등** + **화난 강아지** | [ ] |
| 2 | 정상 댓글 입력 테스트 (예: "오늘 날씨가 좋네요") | `"악플이 아닙니다."` + **초록불** + **웃는 강아지** + `"다시 입력해주세요"` | [ ] |
| 3 | 빈 댓글 입력 후 판별 클릭 | API 호출 없이 안내 메시지 출력 | [ ] |
| 4 | 로그인 없이 피드백 작성 | 에러 없이 Supabase에 저장 및 목록 최상단 즉시 반영 | [ ] |
| 5 | 페이지 새로고침 후 피드백 확인 | 기존 피드백들이 **최신순**으로 유지됨 | [ ] |

---

## 2. UI/UX 및 보안 검증
- [ ] **디자인 일관성**: 첨부 이미지(OXFAM Trailwalker)와 같은 딥 그린(`#0B4F28`) + 옐로우(`#FACC15`) 테마가 적용되었는가?
- [ ] **보안**: 브라우저 개발자 도구(F12 > Sources/Network)에서 `OPENAI_API_KEY`가 노출되지 않는가?
- [ ] **반응형**: 모바일 화면에서도 버튼과 입력창이 화면 밖으로 넘치지 않는가?

---

## 3. Vercel 배포 확인
- [ ] Vercel 환경변수에 `OPENAI_API_KEY`, `SUPABASE_URL`, `SUPABASE_ANON_KEY`가 모두 등록되었는가?
- [ ] 배포된 URL에서 판별 기능과 피드백 기능이 모두 정상 작동하는가?
