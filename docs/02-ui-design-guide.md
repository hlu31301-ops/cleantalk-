# 02. UI 구현 지침 (첨부 이미지 스타일 + 강아지 캐릭터)

첨부된 참고 이미지(**OXFAM Trailwalker** 웹페이지 목업)의 시각적 톤앤매너를 바탕으로, 악플 판별 서비스에 맞게 UI를 구현합니다.

---

## 1. 컬러 팔레트 (Color System)
참고 이미지의 **신뢰감 있는 딥 그린 + 깔끔한 화이트 + 포인트 옐로우** 조합을 그대로 사용합니다.
- **Primary Deep Green**: `#0B4F28` (상단 공지 바, 하단 피드백 섹션 배경)
- **Secondary Green**: `#146C3B` (카드 배경 또는 호버 상태)
- **Accent Yellow**: `#FACC15` (핵심 CTA 버튼, 강조 배지 — 참고 이미지의 노란색 원형 버튼 스타일)
- **Background Light**: `#F8FAF9` (본문 기본 배경)
- **Text Dark**: `#111827` (기본 본문 텍스트)
- **Text White**: `#FFFFFF` (딥 그린 배경 위 텍스트)
- **Status Red (경고등)**: `#EF4444` (악플일 때 켜지는 경고등)
- **Status Green (초록불)**: `#22C55E` (악플이 아닐 때 켜지는 초록불)

---

## 2. 레이아웃 구조 (위에서 아래로)
1. **상단 공지 바 (Top Banner)**
   - 배경: `#0B4F28`, 높이 약 `36px`, 중앙 정렬 흰색 텍스트
   - 내용 예: `"건전한 댓글 문화를 함께 만들어가는 AI 악플 판별 서비스"`
2. **네비게이션 헤더 (Header)**
   - 좌측: 서비스 로고 (`CleanTalk`)
   - 우측: 간단한 앵커 메뉴 (`판별하기`, `피드백 남기기`)
3. **히어로 & 악플 판별 섹션 (Hero Section)**
   - 참고 이미지처럼 웅장하고 깔끔한 타이틀 배치: `"우리의 작은 배려로 함께 만드는 건강한 댓글 문화"`
   - 중앙 카드:
     - **댓글 입력창 (`<textarea>`)**: 사용자가 댓글을 입력하는 영역
     - **판별하기 버튼**: 포인트 옐로우(`#FACC15`) 배경, 짙은 글씨, 둥근 모서리
   - **판별 결과 표시 영역 (신호등 + 강아지 캐릭터)**:
     - 판별 전에는 대기 상태 안내
     - 판별 후에는 **신호등(빨강/초록 불빛 애니메이션)** + **귀여운 강아지 캐릭터** + **결과 문구** 표시
4. **하단 피드백 섹션 (Footer / Feedback Section)**
   - 참고 이미지 하단의 짙은 초록색(`#0B4F28`) 영역 스타일 적용
   - 좌측/상단: 피드백 작성 폼 (닉네임 선택입력, 피드백 내용, 전송 버튼)
   - 우측/하단: Supabase에서 불러온 **최신순 피드백 목록** (깔끔한 화이트/반투명 카드 형태)

---

## 3. 귀여운 강아지 캐릭터 구현 지침
외부 이미지 깨짐을 방지하기 위해 **인라인 SVG** 또는 **CSS로 스타일링된 고해상도 이모지/SVG 일러스트**를 사용합니다.
- **대기 상태**: 🐶 평온한 강아지 ("댓글을 입력하면 제가 판별해 드릴게요!")
- **악플일 때 (화난 표정)**: 😠🐶 눈썹이 찌푸려지고 볼이 빨개진 화난 강아지 + 빨간 경고등 점등
- **악플이 아닐 때 (웃는 표정)**: 😊🐶 눈웃음을 짓고 하트가 뜬 행복한 강아지 + 초록불 점등

---

## 4. 완료 및 검증 기준
- [ ] `#0B4F28` 딥 그린과 `#FACC15` 옐로우 포인트 컬러가 적용되었는가?
- [ ] 악플 여부에 따라 신호등 색상(빨강/초록)과 강아지 표정(화남/웃음)이 명확히 바뀌는가?
- [ ] 모바일(375px)과 데스크탑(1280px)에서 레이아웃이 깨지지 않는가?
